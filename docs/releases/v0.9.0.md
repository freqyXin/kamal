# K'amal v0.9.0

## Overview

K'amal v0.9.0 introduces evidence-backed BLE intelligence findings
within offline assessments.

## New capabilities

- Validate assessment findings and their evidence references.
- Resolve evidence JSON Pointers against preserved source reports.
- Reject duplicate finding identifiers and invalid evidence paths.
- Generate conservative BLE intelligence findings automatically.
- Preserve explicit control over finding generation.

## BLE-GATT-001

Identifies successfully enumerated GATT characteristics advertising
the Write Without Response property.

Classification:
- Severity: informational
- Confidence: low
- Status: potential

The finding identifies characteristics requiring security review.
It does not establish that writes succeed, bypass authentication,
or affect security-sensitive functionality.

No characteristic writes or pairing tests are performed by this rule.

## Report schemas

- Passive BLE: 0.6.0
- Active GATT: 0.7.0
- Assessment: 0.9.0

These schema versions are independent of application versions.

## Limitations

- No automatic device identity correlation.
- No confirmed vulnerability determination.
- Finding identifiers depend partly on enumeration order.
- Baseline source-report validation is not exhaustive.
- Original source files must be retained for independent hash verification.

## Testing

The development test suite passed 102 tests with one expected skip.
An additional end-to-end CLI test confirmed automatic finding
generation, evidence-path resolution, and integrity counts.
