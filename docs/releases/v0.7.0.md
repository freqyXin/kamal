# K'amal v0.7.0

Release: September 17, 2026

Git tag: `v0.7.0`

## Overview

K'amal v0.7.0 adds offline Bluetooth SIG identifier resolution
to active BLE GATT enumeration.

This release builds on the passive BLE inventory and active GATT
enumeration capabilities introduced in earlier versions.

## Capabilities

### Passive BLE inventory

`kamal-scan` processes an existing BLE PCAP using tshark.

It provides:

- Advertiser inventory and packet counts.
- Advertising names and advertised service UUIDs.
- Manufacturer data.
- RSSI and channel observations.
- Scan-request observations.
- CRC integrity accounting.
- Offline Bluetooth SIG identifier resolution.
- JSON and CSV output.

Passive observations do not establish physical device identity
or prove that GATT services were enumerated.

### Active BLE GATT enumeration

`kamal-gatt` uses the Raspberry Pi's BlueZ Bluetooth adapter
to connect to an explicitly selected BLE target.

It records:

- Connection and disconnection outcomes.
- GATT services, characteristics, and descriptors.
- Characteristic properties.
- Bluetooth SIG names for recognized UUIDs.
- Unknown UUIDs without speculative identification.
- Identifier registry provenance.

The tool does not explicitly read or write characteristic values,
subscribe to notifications, or request pairing.

GATT metadata discovery may involve protocol-level ATT reads.

### Offline identifier registries

Bluetooth SIG registries are generated locally from a pinned
upstream source revision.

Generated registry JSON files are not distributed in the repository.

See `data/bluetooth/README.md` for generation instructions.

## Report versions

Application version: `0.7.0`

Passive BLE report schema: `0.6.0`

Active GATT report schema: `0.7.0`

These versions are intentionally independent.

## Requirements

Passive inventory requires an existing BLE PCAP, tshark, and
locally generated Bluetooth identifier registries.

Active GATT enumeration requires a compatible Bluetooth adapter,
BlueZ, Bleak, and the locally generated GATT identifier registries.

The Nordic BLE sniffer is used for passive packet capture.
It is not the adapter used by the active GATT command.

## Limitations

- No automatic correlation between passive and active reports.
- No automatic vulnerability determination.
- No explicit characteristic value reads or writes.
- No notification subscriptions or pairing requests.
- Unknown vendor UUIDs remain unresolved.

Use these capabilities only with appropriate authorization.
