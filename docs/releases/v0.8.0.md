# K'amal v0.8.0

## Overview

K'amal v0.8.0 introduces unified offline BLE assessments.

## New capabilities

- Combine passive BLE and active GATT JSON reports.
- Preserve original report evidence and SHA-256 source provenance.
- Validate supported report structures before import.
- Reject duplicate sources and prevent output overwrites.
- Keep passive and active observations separate.
- Provide an offline assessment CLI.

## Report schemas

- Passive BLE: 0.6.0
- Active GATT: 0.7.0
- Assessment: 0.8.0

These schema versions are independent of the application version.

## Limitations

- No automatic device identity correlation.
- No automatic vulnerability determination.
- Baseline structural validation is not exhaustive.
- Original source files must be retained for independent hash verification.
